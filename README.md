# UNFILTERED presentation — fixed

## Open the presentation
1. Extract the entire ZIP file.
2. Keep `index.html`, `style.css`, `script.js`, and `unfiltered-clothing.png` together in the same folder.
3. Open `index.html` in a modern browser.

The brand image is a local file, so keep it beside `index.html`. Internet is only needed for optional web fonts and Font Awesome icons; the presentation and navigation work locally. The layout includes responsive rules for desktop, tablet, and mobile screens, plus scrolling for short screens.
